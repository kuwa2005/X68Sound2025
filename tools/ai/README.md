# AI による ADPCM 高音質化：学習ツール

`X68SOUND_AI_ENHANCE=1`（mxwav では `-A`）で使うニューラルネットの学習プログラムです。
外部ライブラリは使わず、C++ だけで学習します。

## 仕組み
- ADPCM をデコードした値とステップ幅を、それぞれ前後のサンプル（過去16・未来8）分まとめて入力します。中央サンプルの量子化誤差を、ステップ幅で正規化した値として予測し、補正します。
- モデルは MLP（52-40-40-1、活性化関数 tanh）で、パラメータ数は約3,800です。補正量は ±1 ステップに制限しています。
- 出力は8サンプル遅れます。この遅延と計算量のため、オフライン描画（`X68Sound_StartPcm`）のときだけ有効にしています。
- 学習データは**すべて合成音**で、録音物や著作物は使っていません。種類は楽音、撥弦音、ノイズ・打楽器、キック、声のような音、正弦波、チャープ、パルス、FM 音、それらの混合です。サンプルレートは X68000 の ADPCM の5種類（3.9〜15.6kHz）を使います。

## 学習
```sh
g++ -O3 -march=native -std=c++14 train_adpcm_enhancer.cpp -o train
./train ../../X68Sound/ai_model.h 480     # 2つ目の引数は学習時間の上限（秒）
```
乱数シードは固定しているので、同じ環境なら同じモデルが得られます。
エポックごとに評価用データで「全体の改善量」と「最も悪化した種類」を評価し、悪化する種類が出ないモデルを優先して保存します。

## 現在のモデルの評価（`X68Sound/ai_model.h` 冒頭にも記録）
学習に使っていない合成データで評価した結果です。**全10種類で改善し、悪化した種類はありません**（+0.4〜+3.1dB）。

実際の再生経路での測定値は次のとおりです（テストで確認）。
- PCM8 の ADPCM（700Hz の正弦波）：THD+N 2.43% → 1.40%（4.8dB 改善）
- mxwav（MSM6258、1kHz の正弦波、`X68SOUND_PCM_RESAMPLE=1` 併用）：THD+N 3.26% → 2.16%（3.6dB 改善）
- 学習に含めていないノコギリ波：+0.6dB

## 経緯（参考）
- **v1**：合成データの評価では +3.3dB でしたが、実際の経路ではほぼ効果がありませんでした。
- **v2**：信号の種類を増やしたところ、パルス波の大きな誤差が学習を支配し、多くの種類で悪化しました。
- **v3（現行）**：学習目標を推論時と同じ ±1 ステップにクリップし、悪化を罰する基準でモデルを選ぶようにして、全種類で改善しました。
