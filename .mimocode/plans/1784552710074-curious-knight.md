# X68Sound2025 高音質化計画

## 概要
既存の音質向上機能（線形補間、ボリュームスムージング、ハイレゾ出力等）の更なる改善。

## Phase 1: 高影響度・低工数（クイックウィン）

### 1.1 OPM最終出力のハードクリッピング → ソフトクリッピング
- **ファイル**: opm.h:1177-1191
- **問題**: `PCM_LIMITS` で直接クリッピング → 音割れがひどい
- **修正**: 既存の `ApplySoftClipping()` を呼ぶように変更
- **効果**: 大音量時の歪みが劇的に改善

### 1.2 FM ChorusのLFOをサンプルレート連動
- **ファイル**: audioeffects.h:256
- **問題**: `fm_chorus_lfo_phase += 2` が固定値 → 96kHzで2倍速
- **修正**: `(2 * 48000) / sample_rate` でスケーリング
- **効果**: 全サンプルレートで一貫したコーラス効果

### 1.3 PCM8ボリュームスムージングの時間ベース化
- **ファイル**: pcm8.h:351-363
- **問題**: ステップ数固定 → 高サンプルレートでクリック再発
- **修正**: ステップ数を `(44100 / Samprate)` でスケール
- **効果**: 全サンプルレートで安定したスムージング

## Phase 2: 高影響度・中工数（コア品質）

### 2.1 サインテーブル解像度の向上
- **ファイル**: global.h:355-361, opm.h:590-591
- **問題**: 1024エントリ/short → 位相量子化ノイズ
- **修正**: 4096エントリ/int に拡張（`SIZESINTBL_BITS=12`）
- **効果**: FM音色の滑らかさ向上（特にベース・パッド）

### 2.2 サイン波線形補間 → 放物線補間
- **ファイル**: op.h:531-541（全Output関数）
- **問題**: 線形補間 → 2次倍音歪みを系統的に生成
- **修正**: 放物線補間（3点lookup + 補正項）に変更
- **効果**: FM音源の倍音歪みを排除

### 2.3 ハイレゾ出力時のローパスフィルタ調整
- **ファイル**: global.h:688-703, opm.h:1140-1171
- **問題**: 96kHz/192kHz出力でも44.1kHz用FIRを使用
- **修正**: サンプルレートに応じたFIR係数セットを生成
- **効果**: ハイレゾ出力の本来の音質を実現

## Phase 3: 中影響度・低工数（レート正しさ）

### 3.1 リバーブのダンピングフィルタ追加
- **ファイル**: audioeffects.h:328-332
- **問題**: コンブフィルタ内にローパスダンピングがなく金属的
- **修正**: フィードバックループ内に1次ローパスフィルタ追加
- **効果**: より自然で温かいリバーブ音

### 3.2 リバーブ遅延時間のサンプルレート連動
- **ファイル**: audioeffects.h:82-89
- **問題**: コンブ遅延が48kHz固定 → 96kHzで部屋サイズが半分
- **修正**: `delay = base_delay * (sample_rate / 48000)` でスケーリング
- **効果**: 全サンプルレートで一定のリバーブ特性

### 3.3 HPFフィルタのサンプルレート適応
- **ファイル**: adpcm.h:564-568, global.h:629
- **問題**: `HPF_COEFF_A1_22KHZ = 459` が22kHz固定
- **修正**: サンプルレートに応じて係数を計算
- **効果**: 高サンプルレートでも適切なカットオフ周波数

## Phase 4: 低影響度・改善

### 4.1 出力ディザリング
- **ファイル**: opm.h:~1196
- **問題**: 16bit丸め → 量子化ノイズフロア
- **修正**: TPDF ディザを適用
- **効果**: 静寂区間のノイズフロア改善

### 4.2 ノイズジェネレータのLFSR化
- **ファイル**: global.h:665-668, op.h:626-628
- **問題**: LCG → 周期成分あり
- **修正**: 17ビットLFSR（実機YM2151互換）に変更
- **効果**: ノイズモードの音質向上

## 検証方法
- 既存テストsuite（28件）で回帰なしを確認
- 各改善前にベースライン波形をキャプチャ
- 改善後に聴覚テスト + スペクトル分析
